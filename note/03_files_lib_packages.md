## ファイル
 * `go.mod`  - 「どのライブラリを使うか」を書くファイル
 * `go.sum`  - ダウンロードしたライブラリが改ざんされていないか確認するためのチェックサムを記録するファイル


## go mod
Composer, npm に相当

| 主なコマンド       | 役割                      |
| ----------------- | ----------------------- |
| `go mod init`     | プロジェクトを作る（`go.mod` を作成） |
| `go mod tidy`     | 使っているライブラリだけに整理する       |
| `go mod download` | ライブラリをダウンロードする          |
